# ติดบ้าน — คู่มือติดตั้ง

> **ติดตั้งแล้ว (9 พ.ย. 2026)**
> - แอพ: https://all9tum.github.io/tid-baan/
> - Google Sheet: https://docs.google.com/spreadsheets/d/1bBq8KssdreaGjuzlyv52ukZkyElwUR4jiv9gYdGAaDI/edit
> - Apps Script: โปรเจกต์ "บ้านมีของ API" (ชื่อเดิม) (สคริปต์แยก ผูกกับชีตผ่าน `SHEET_ID` ในโค้ด)
> - Web app URL / API KEY: ดูใน Apps Script › Deploy › Manage deployments และฟังก์ชัน `showApiKey`

แอพจัดการของในบ้าน ข้อมูลเก็บใน Google Sheet ของเราเอง ใช้บนมือถือเป็นหลัก ดูแดชบอร์ดบนคอมได้

```
baan-mee-khong/
├── apps-script/Code.gs   ← หลังบ้าน (วางใน Google Sheet)
└── web/index.html        ← หน้าเว็บ (ไฟล์เดียวจบ)
```

ลองก่อนก็ได้: เปิด `web/index.html` แล้วกด "เปิดโหมดตัวอย่าง" ใช้ข้อมูลจำลองในเครื่อง ไม่ต้องตั้งค่าอะไร (กล้องจะใช้ได้เมื่อเปิดผ่าน https เท่านั้น)

---

## ขั้นที่ 1 — สร้าง Google Sheet + API (ประมาณ 5 นาที)

1. เปิด https://sheets.new ตั้งชื่อชีต เช่น `ติดบ้าน`
2. เมนู **Extensions › Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs` กด 💾 Save
4. เลือกฟังก์ชัน `setup` ที่แถบบน แล้วกด **Run**
   - ครั้งแรก Google จะขอสิทธิ์ › เลือกบัญชี › Advanced › Go to … (unsafe) › Allow
     (ขึ้น "unsafe" เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ผ่านการรีวิวจาก Google)
   - เปิด **Execution log** จะเห็น `API KEY ของคุณคือ: xxxxxxxx` — จดไว้
   - กลับไปดูชีต จะมีแท็บ Items, Groups, Transactions, Categories, Settings
5. กด **Deploy › New deployment** › รูปเฟือง › **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> "Anyone" แปลว่าใครมี URL ก็เรียกได้ แต่ทุกคำขอต้องมี API KEY ถูกต้อง ไม่งั้นถูกปฏิเสธ อย่าแชร์ทั้งสองอย่างคู่กัน

ลืม API KEY: ใน Apps Script เลือกฟังก์ชัน `showApiKey` แล้วกด Run

## ขั้นที่ 2 — เอาหน้าเว็บขึ้น GitHub Pages (ฟรี)

กล้องสแกนบาร์โค้ดต้องเปิดผ่าน https จึงต้องโฮสต์หน้าเว็บ

1. สร้าง repo ใหม่ใน GitHub (เช่น `baan-mee-khong`) เป็น Public หรือ Private ก็ได้ถ้ามี GitHub Pro
2. อัปโหลด `web/index.html` ไว้ที่ราก repo
3. **Settings › Pages** › Source: Deploy from a branch › Branch: `main` / root › Save
4. รอ 1–2 นาที จะได้ลิงก์แบบ `https://<username>.github.io/baan-mee-khong/`

ทางเลือกอื่นที่ใช้ได้เหมือนกัน: Netlify Drop (ลากไฟล์ไปวาง) หรือ Cloudflare Pages

## ขั้นที่ 3 — เชื่อมต่อ

1. เปิดลิงก์บนมือถือ › ใส่ **Web app URL** + **API KEY** + ชื่อเล่น › บันทึกและเชื่อมต่อ
2. ทำเป็นไอคอนบนหน้าจอ: iPhone › Share › Add to Home Screen / Android › ⋮ › Add to Home screen
3. ค่าที่ตั้งไว้เก็บในเครื่องนั้น เปิดบนคอมต้องใส่อีกครั้ง

## วิธีใช้

| ทำอะไร | ทำยังไง |
|---|---|
| เพิ่มของเข้าระบบครั้งแรก | สแกน (โหมดปกติ) › ของใหม่จะเปิดฟอร์มให้ › กรอก "ตอนนี้มีอยู่กี่หน่วย" |
| หยิบของมาใช้ | สแกน › ปรับจำนวน › **ตัดจำนวน** (กดเลิกทำได้ภายใน 6 วินาที) |
| ไปซูเปอร์ฯ | แท็บ Shopping › สแกนหยิบลงตะกร้า › แก้ราคาถ้าไม่ตรง › **Buy** |
| ไม่ซื้อบางอย่างรอบนี้ | กด ✕ ที่รายการเทา (หายแค่รอบนี้) |
| ไม่อยากให้เตือนเลย | เปิดรายละเอียดสินค้า › ปิด "เตือนเมื่อใกล้หมด" |
| รวมยี่ห้อเป็นกลุ่มเดียว | แก้ไขสินค้า › ใส่ช่อง "กลุ่ม" ให้เหมือนกัน |
| นับของจริงแล้วไม่ตรง | รายละเอียดสินค้า › นับสต็อกใหม่ |

เกณฑ์เตือน: ทั้งกลุ่มเหลือ ≤ 1 = ต้องซื้อ, เหลือ 2 = ใกล้หมด แก้ได้ที่แท็บ **Settings** ในชีต

ตะกร้าเก็บในมือถือจนกว่าจะกด Buy เน็ตหลุดในร้านก็สแกนต่อได้ ใช้เน็ตตอนกด Buy ครั้งเดียว

## แก้โค้ด Apps Script ทีหลัง

แก้แล้วต้อง **Deploy › Manage deployments › ✏️ › Version: New version › Deploy** URL เดิมจะใช้ต่อได้
(ถ้ากด New deployment จะได้ URL ใหม่ ต้องไปใส่ในแอพใหม่)

## แก้ปัญหา

- **เปิดกล้องไม่ได้** — ต้องเปิดผ่าน https และกดอนุญาตกล้อง ถ้ายังไม่ได้ พิมพ์เลขบาร์โค้ดใต้กล้องแทนได้
- **เชื่อมต่อไม่สำเร็จ** — เช็คว่า URL ลงท้าย `/exec`, Who has access เป็น Anyone, API KEY ถูกตัวพิมพ์
- **บาร์โค้ดเลข 0 ข้างหน้าหาย** — `setup()` ตั้งคอลัมน์ barcode เป็นข้อความไว้แล้ว ถ้าพิมพ์ลงชีตเอง ให้ใส่ `'` นำหน้า
